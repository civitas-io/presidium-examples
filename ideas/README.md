# Ideas: Complex Workflow Backlog

> Briefs for future examples. Each targets a different enterprise domain and leads with the governance story, not the technical complexity.

---

| Idea | Domain | Signature primitive | Stakes |
|---|---|---|---|
| [Finance Close Automation](finance-close.md) | Finance | Multi-agent supervision + SOX audit trail | Regulatory |
| [Legal Contract Review](contract-review.md) | Legal | Outcome-driven trust decay (closed loop) | Financial liability |
| [Supply Chain Risk + Procurement](supply-chain.md) | Operations | Spend-ceiling credentials + intent declaration | Financial commitment |
| [IT Change Management](change-management.md) | DevOps | Time-window policy + environment-scoped credentials | Production stability |
| [Clinical Data Pipeline](clinical-pipeline.md) | Healthcare | Consent-scoped vault tokens + regulatory audit | HIPAA / FDA |
| [Governed Coding Agent](hard-coding-agent.md) | DevOps / Engineering | Drift detection + credential scoping + git-aware policy + trust-gated autonomy | Production stability |
| [Personal AI Assistant](personal-assistant.md) | Consumer | Personal consent model + approval gates for irreversible actions | Trust at human scale |

The coding agent is the most developer-relatable hard example — every engineering team is already deploying coding agents with no governance. The personal assistant is the consumer-facing counterpart — same primitives, different audience.
